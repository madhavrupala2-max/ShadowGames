# SHADOW ARCADE

Laptop / TV = big screen, phones = controllers (up to 8 players). Works on the same Wi-Fi.

## Run
```
npm install
node server.js          # open http://localhost:3000 on the big screen, scan the QR with phones
```

## GYANI QUIZ (KBC style, Hindi + English)
* Host = Player 1 (★). Host picks 10 / 20 / 30 questions on his phone.
* Everyone answers A/B/C/D, no time limit. Screen shows **who** has answered (not what).
* Host presses **COMPUTER JI** -> suspense -> right answer + everybody's picks show. Then **AGLA SAWAL**.
* Total score for every player at the end.
* Questions are generated by **Gemini** (REST call, same as curl) - nothing is saved, and the game sends the
  already-asked questions back to Gemini so nothing repeats. Hindi + English text, spoken by the browser voice (M = voice on/off).
* Setup: copy `.env.example` to `.env` and put `GEMINI_API_KEY=...`. Without a key a small offline bank (24 questions) is used.

## Adding a new game (zero edits elsewhere)
Drop one `.js` file in `public/js/games/` that calls `AX.register({...})` (copy any existing game as a template; files starting with `_` are ignored).
The server lists the folder at `/games.json` and the host page loads every file automatically. `order` decides menu position (6 games per page).

## Android TV slow? -> LITE mode
Lite = no glow, canvas capped at 1280x720, 30 fps, fewer particles (up to ~9x less drawing).
* Turns ON automatically on Android TV browsers, and by itself if the FPS drops below 40.
* Manual: **GRAPHICS** button on Player-1's phone (menu screen), key **G**, or open `http://IP:3000/?lite=1` (`?lite=0` = full).
* Other TV tips: use Chrome / Puffin TV browser (not the tiny built-in WebView); or plug a laptop into the TV by HDMI
  (best), or cast the laptop's Chrome tab. TV box with 1 GB RAM: close other apps.
